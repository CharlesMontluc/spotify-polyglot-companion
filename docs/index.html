    How it works

    From the song playing to a line you can read.

    1. 1

      Detect the track

      A content script reads the title, artist and position from the Spotify Web Player and the browser's Media Session. No Spotify login, so no Premium needed.

    2. 2

      Fetch the lyrics

      The background worker asks LRCLIB for time-synced lyrics, matching on title, artist and duration. Plain lyrics are spread across the song instead.

    3. 3

      Transliterate & translate

      Each line gets a translation and a romanization. For Arabic and Hebrew, a built-in rule-based transliterator fills the gaps, vowel marks and doubled letters included.

    4. 4

      Follow the music

      The panel highlights the current line and scrolls with the song. A ±8 s sync offset fixes lyrics that run early or late.

    Any script

    Greek, Cyrillic, Japanese, Korean, Arabic, Devanagari, Hebrew — anything LRCLIB has lyrics for.

    Four display modes

    Both lines, translation only, transliteration only, or just the original.

    Five target languages

    English, French, Spanish, German and Portuguese.

    Stays out of the way

    Drag it, resize it, minimize it. Position and settings are remembered.

    Follow or browse

    Let it follow the song, or scroll freely and jump back to the current line.

    No account

    Works on the free Spotify Web Player, without any API key or login.

    In action

    On real songs.

    Install

    Two minutes, in developer mode.

    1. Download the code and unzip it.
    2. Open chrome://extensions and turn on Developer mode.
    3. Click Load unpacked and choose the extension folder.
    4. Open open.spotify.com and play a song.

    Good to know

    • Not on the Chrome Web Store yet.
    • Lyric coverage depends on LRCLIB.
    • Romanization without vowel marks (Arabic, Hebrew) is approximate.
    • If Spotify changes its page, detection may need an update.
